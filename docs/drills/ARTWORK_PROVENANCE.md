# Offline drill artwork provenance

The 18 bundled plates were newly generated for CourtQuest Pro through Replit's
image-generation tool. Athletes are synthetic adults in unbranded sports clothing;
no third-party athlete photograph, team identity, logo, or runtime image service
is used. The approved CourtQuest branding and original jersey resources were not
modified. No external paid image API was added to the app.

Images were visually reviewed against each built-in drill's written instructions
before conversion to lossy WebP. The box-out plate was cropped to remove a lower
panel depicting extended-arm contact. Five plates intentionally omit a visual
mistake comparison: valid hand/pass variants or safe spacing are preferable to a
misleading or unsafe negative example. The exact per-drill decisions are in
`DRILL_ART_COVERAGE.md`.

Generated artwork is a coaching aid, not expert biomechanical certification or a
substitute for the written instructions. Full-resolution source exports are not
needed by the application; only the optimized offline WebPs are bundled.
